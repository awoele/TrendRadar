## 概述

整体采用浅灰画布、白色数据表面和深色交互状态，强调信息可信度与浏览效率。参考模板的中性色、紧凑工具栏和卡片层级被保留；复杂图表和过小字号未迁移。热点卡恢复原版的图片/受控渐变封面、叠加标题和来源徽标，用更高的展示区强化内容识别。

## 颜色

### 品牌与强调色

- `--navy: #182033`：主交互、选中平台、品牌标识。
- `--blue: #2563eb`：链接、搜索类内容和键盘焦点。
- `--green: #0f8f65`：数据有效状态、当前结果和抖音收藏。
- `--purple: #6d5bd0`：选题标签与未知平台兜底。
- `--red: #c2413d`：小红书平台细节色。

### 表面色

- `--canvas: #f4f6fb`：页面画布，来自参考模板的精确值。
- `--panel: #ffffff`：工具栏、搜索面板、内容卡和采集记录。
- `#fbfcfe`：展开后的次级记录区域。

### 文字色

- `--ink: #182033`：标题和主要数据。
- `--ink-soft: #314056`：按钮外的重点文字。
- `--muted: #68798d`：说明、平台和元数据。
- `--quiet: #8794a6`：低优先级辅助信息。

### 语义色

- 成功 / 有效：`#0f8f65`，浅底 `#e9f7f1`。
- 信息 / 链接：`#2563eb`。
- 风险：`#c2413d`。
- 警告：`#b7791f`。

## 排版

### 字体家族

正文使用 `Inter, ui-sans-serif, system-ui, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`；内部标识和来源 ID 使用 `Cascadia Mono, Consolas, monospace`。

### 层级表

| Token | 字号 | 字重 | 行高 | 字距 | 用途 |
|---|---:|---:|---:|---:|---|
| display | 22–25px | 800 | 1.2 | -0.025em | 页面标题 |
| section | 18px | 800 | 1.3 | -0.015em | 模块标题 |
| card-title | 16px | 760 | 1.42 | -0.01em | 热点标题 |
| body | 14px | 400 | 1.5 | 0 | 常规内容 |
| metadata | 11–12px | 400–750 | 1.35–1.5 | 0 | 作者、时间、平台与说明 |
| utility | 9–10px | 700–800 | 1 | 0.11em（仅英文标签） | 徽标、状态和内部分类 |

### 原则

- 中文标题不使用全大写或斜体；英文 eyebrow 可使用大写与正字距。
- 数据使用 tabular numbers，标题最多两行，摘要最多两行。
- 不照搬参考模板中大量 10–11px 正文；小字号只用于辅助信息。

## 布局与间距

### 间距系统

基础步长为 4px，常用值为 7、12、14、18、24px。工具栏内边距为 16–18px，内容卡内边距为 14–16px，模块间距为 14–18px。

### 网格 / 容器

- 最大内容宽度：`1440px`（参考模板精确值）。
- 桌面热点卡：4 列；`≤1180px` 变 3 列；`≤980px` 变 2 列；`≤700px` 变 1 列。
- KPI：作为只读数据条嵌入平台筛选首行，四项始终紧凑排列，不使用独立卡片。
- 搜索与高级筛选摘要位于同一排；高级筛选项桌面 6 列，`≤1180px` 变 3 列，`≤980px` 变 2 列，`≤700px` 变 1 列。

### 留白习惯

品牌头与工具栏保持 18px 间隔；卡片之间使用 12–13px；页面外围桌面保留 24px 以上安全边距，移动端为 12px。

## 圆角与形状

| Token | 值 | 用途 |
|---|---:|---|
| control | 7px | 输入框、按钮、平台 Tab |
| surface | 8px | 工具栏、搜索面板、内容卡、弹层 |
| pill | 999px | 状态、来源、热度和标签 |

品牌标识使用 8px 圆角方形，不使用圆形 Logo；平台色只作为小面积语义提示。

## 阴影与深度

- Level 0：无阴影，用于输入框和卡内分隔。
- Level 1：`0 8px 20px rgba(22,32,51,.045)`，来自参考模板的精确卡片阴影。
- Level 2：`0 16px 36px rgba(22,32,51,.16)`，仅用于导航弹层。
- Hover：`0 14px 30px rgba(22,32,51,.09)`，同时上移 2px。

## 组件样式

### 品牌头

标题/副标题 + 右侧“内容 / 统计 / 配置”显式页面标签 + 数据快照状态；不使用无说明的缩写图标。移动端标题与操作区纵向排列。

### 集中工具栏

平台 Tab、四项只读数据、排序和重置位于第一排白色工具栏；搜索与“更多筛选”位于第二排。按钮高度 38px、7px 圆角；选中平台统一使用深色底。移动端以平台下拉替代横向 Tab。

### 只读数据条

四项紧凑数据展示总量、当前结果、活跃平台和热度峰值，以细分隔线融入平台筛选行，不使用阴影、悬浮或指针光标，明确它们不可点击。热度峰值只展示当前结果中可用的最高热度分；若当前平台没有热度分，则切换为最高点赞口径。“当前结果”数值使用绿色，形成唯一强调。

### 内容卡

卡片恢复原版的封面叠加标题、来源徽标和正文信息层级；桌面展示区高度为 232px，移动端为 220px，给图片和无图渐变留出完整视觉空间。正文包含来源类型、平台、热度、标题、证据元数据、最多四个标签、摘要与原文入口。卡片顶部 3px 细线按同一指标组内的相对强度确定长度：热度分只与热度分比较，只有点赞数据的内容只在点赞组内比较；平台只决定细线颜色。

### 高级筛选与采集记录

高级筛选使用可折叠白卡，并与搜索面板同排；摘要行明确说明内容并显示启用数量。采集记录独立折叠，来源使用公共来源名称，不展示本地文件路径。

### 状态

加载、空结果和失败状态均占据独立表面；键盘焦点使用蓝色 3px focus ring；遵循 `prefers-reduced-motion`。

## 注意事项（Do's and Don'ts）

- **应做**：让总量、筛选结果、更新时间和热度在首屏可见。
- **应做**：用中性色建立主层级，用平台色表达来源，用绿色表达有效状态。
- **应做**：桌面四列、窄桌面三列、平板两列、手机单列，并限制一次渲染的卡片数量。
- **不应做**：在正文内部反复堆叠同一元数据或展示内部平台 ID；封面与正文的双标题仅用于兼顾视觉识别和原文访问。
- **不应做**：在封面之外扩散多种强色；无图封面只能使用受控色板，不新增随机颜色。
- **不应做**：把采集记录、本地路径或技术实现细节置于主浏览路径。
- **不应做**：通过压缩字号容纳更多字段；低优先级内容应折叠或截断。

## 附注

参考模板的色值、最大宽度、圆角和阴影来自浏览器计算样式；热点卡网格、字号上调、热度细线与渐进加载是针对 TrendRadar 内容浏览任务的适配决策。
